# CSC584 - Individual Assignment 1: Personal Profile Web Application

## Project Description
A simple Java EE web application that collects user profile details (Name, Student ID, Programme, Email, Hobbies, and Self-Introduction) via an HTML form, processes the request using a Java Servlet (HTTP POST), and displays the submitted information on a JSP page.

## Technologies Used
* **IDE:** Apache NetBeans 8.2
* **JDK:** Java SE Development Kit 8u202
* **Server:** GlassFish Server (Java EE 7 Web)
* **Frontend & Backend:** HTML5, CSS3, Java Servlets, JavaServer Pages (JSP)

## How to Run the Application
1. Clone or download this repository to your local machine.
2. Open **NetBeans IDE 8.2**.
3. Go to **File > Open Project** and select the **PersonalProfileApp** folder.
4. Right-click the project in the **Projects** panel and select **Run** (or press F6).
5. The application will open automatically in your default web browser at  http://localhost:8080/PersonalProfileApp/
